---
title: PR review comments
description: Unresolved review threads on this branch's PR, condensed.
---

```sh
proof pr comments                  # unresolved threads for this branch's PR, plus reviews and comments
proof pr comments 123              # a specific PR
proof pr comments --all            # include resolved threads
proof pr comments --no-bots --full
```

Each thread shows its `path:line`, so an agent can find the code and address it. Uses your `gh` login.
